# Trend Mart Luxe

Mobile-first e-commerce storefront for GitHub Pages.

## Files
- `index.html` — website structure
- `style.css` — responsive design
- `script.js` — products, search, filters and cart
- `assets/logo.jpg` — supplied logo
- `assets/hero.jpg` — supplied hero image

## Add products later
Open `script.js` and add another object inside `products`, for example:

{ id:9, name:"New Product", category:"Jewellery", price:899, icon:"💍" }

For real product photos, the product card can also be changed to use image paths.

## GitHub Pages
1. Upload all files/folders to the root of your GitHub repository.
2. Go to Settings → Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/root`, then Save.
5. GitHub will provide your live website link.

Payment/WhatsApp checkout can be connected after the storefront is live.
